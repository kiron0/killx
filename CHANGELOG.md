# Changelog

## 0.1.0

- Add safe port-based termination with SIGTERM, force mode, and timed escalation.
- Add info, check, list, free-port, process search, wait, watch, and development-server commands.
- Add multiple-port and range handling, JSON, quiet output, aliases, colors, and stable exit codes.
- Support macOS, Linux, and Windows inspection and termination.
- Modern TypeScript/Node.js CLI package with zero non-interactive runtime dependencies.
